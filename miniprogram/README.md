# 手之劤产品微信小程序

按商城首页做的微信小程序：黑色顶栏、搜索、品牌轮播、双列商品，以及分类、订单、我的。

用微信开发者工具打开本目录（`miniprogram`）。`project.config.json` 里的 AppID 是 `touristappid`，测试号可以直接预览；上线前换成自己的小程序 AppID。

商品图是按页面结构画的原创插画，用来还原布局。截图里看不清价格的两件商品暂定为：12寸无刷链条锯 ¥268，1033无刷扳手 ¥198。客服电话 `400-108-0888` 和微信号 `kano-hand-tools` 是示例，上线前请改成真实联系方式（`data/catalog.js` 里的 `store`）。

订单保存在手机本地，不经过服务器。「模拟发货」用来在没有后台时把订单从待发货推进到待收货。

不装开发者工具时，可以在这个目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8765/preview/index.html` 看同一套页面。
